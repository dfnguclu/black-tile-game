# Black Tile Game

A fast, browser-based tile-clicking game built with HTML, CSS and JavaScript, developed as a programming project.

## How to play

1. Click the cover page to start a 3-2-1 countdown.
2. Click the black tiles on the 16-tile board. Three black tiles are always active.
3. The faster you click, the more points you get: the score bar starts at 10 and drops by 1 every 100 ms.
4. The game lasts 10 seconds. Your high score is saved in the browser and shown on the cover page.

## Technologies

- HTML, CSS, JavaScript (no frameworks)
- Browser `localStorage` for the high score

## Project structure

| File | Purpose |
|---|---|
| `index.html` | Page that loads the game |
| `style.css` | Styling and animations |
| `game.js` | Game logic: countdown, timer, scoring and high score |

## How to run

Download or clone the repository and open `index.html` in a web browser. No installation is needed.
